# 2. SQL Classes With At Least 5 Students

## Question and image

**2. Sql Classes With At Least 5 Students**

Table: Courses

| Column Name | Type |
|---|---|
| student | varchar |
| class | varchar |

`(student, class)` is the primary key (combination of columns with unique values) for this table.

Each row of this table indicates the name of a student and the class in which they are enrolled.

Write a solution to find all the classes that have at least five students.

**Example 1:**

Example:

Input:

Courses table:

| student | class |
|---|---|
| A | Math |
| B | English |
| C | Math |
| D | Biology |
| E | Math |
| F | Computer |
| G | Math |
| H | Math |
| I | Math |

Output:

| class |
|---|
| Math |

*Explanation:*

- Math has 6 students, so we include it.
- English has 1 student, so we do not include it.
- Biology has 1 student, so we do not include it.
- Computer has 1 student, so we do not include it.

Each row records a student enrolled in a class.

## My solution — SQLite

```sql
SELECT class
FROM Courses
GROUP BY class
HAVING COUNT(student) >= 5;
```

`GROUP BY class` creates one group per class. `COUNT(student)` counts the students in each group, and `HAVING` keeps only classes with at least five students.

`WHERE` filters individual rows before grouping, whereas `HAVING` filters groups after aggregation. Using `GROUP BY` does not automatically require `HAVING`; `HAVING` is needed here because the condition uses the aggregate result `COUNT(student)`.

## My solution — SQL Server

```sql
SELECT class
FROM Courses
GROUP BY class
HAVING COUNT(student) >= 5;
```

The same query works in SQLite and SQL Server.

> **Shared SQL processing note:** `FROM/JOIN → WHERE → GROUP BY → HAVING → SELECT → DISTINCT → ORDER BY → row limiting`. SQLite uses `LIMIT/OFFSET`; SQL Server uses `TOP` or `OFFSET/FETCH`. `WHERE` filters rows before grouping, while `HAVING` filters groups after aggregation. See [SQL Logical Query Processing Order](../0.%20SQL%20basics/SQL%20Logical%20Query%20Processing%20Order.md).
