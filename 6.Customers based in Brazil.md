# 6. Customers based in Brazil

**Difficulty:** Easy  
**Track / database:** SQL / Chinook  
**Practice status:** Final solution saved; viva closed; execution not verified

## Question

The support team needs contact details for every customer located in **Brazil**. From the `Customer` table, return the customers whose `Country` is exactly `'Brazil'`.

Output exactly three columns named `FirstName`, `LastName`, and `Email`.

Sort by `LastName` ascending, then `FirstName` ascending.

**Expected output:** `FirstName`, `LastName`, `Email` · 5 rows · order matters.

Source: [PrepNPlaced SQL practice](https://www.prepnplaced.com/data-practice), “Customers based in Brazil”.

## My thinking process

- I used `=` to match the country.
- I put `Brazil` in single quotes because it is a string.

## My solution

### My final solution

I shared this as my final solution after removing the stray period after `Email`. Pasted line-break escape characters have been removed; my SQL is otherwise preserved as written.

```sql
select FirstName,LastName,Email
from Customer
where Country = 'Brazil'
order by LastName asc , FirstName asc
```

## What I learned

- I corrected the stray period after the last selected column in my final query.
- Single quotes mark `'Brazil'` as a string value in my condition.

- Correction to the supplied explanation: ascending order is the default in `ORDER BY`. Omitting `ASC` alone does not make either sort incorrect; the order of the sort columns still matters.
