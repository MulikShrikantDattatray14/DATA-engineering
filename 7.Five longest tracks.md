# 7. Five longest tracks

**Difficulty:** Easy  
**Track / database:** SQL / Chinook  
**Practice status:** Final solution saved; viva closed; execution not verified

## Question

A radio segment needs the five longest songs in the catalog. From the `Track` table, find the five tracks with the largest `Milliseconds` value, and also express each duration in seconds.

Output exactly three columns: `Name`, `Milliseconds`, and `Seconds`, where `Seconds` is `Milliseconds` divided by `1000.0`.

Sort by `Milliseconds` descending and return only the top 5 rows.

**Expected output:** `Name`, `Milliseconds`, `Seconds` · 5 rows · order matters.

## My thinking process

- I used `1000.0` because the question explicitly specifies that divisor.

- I used descending order to bring the largest duration values to the top, then selected the top five with `LIMIT 5`.

## My solution

### My final solution

My confirmed solution, with pasted line-break escape characters and HTML space entities removed. My SQL is otherwise preserved as written.

```sql
select Name,Milliseconds, (Milliseconds/1000.0) as Seconds
from Track
order by Milliseconds desc
limit 5
```

## What I learned

- Using `1000.0` avoids integer division in this calculation and retains fractional seconds.
- Sorting `Milliseconds` in descending order and then limiting the result to five rows selects the five longest tracks.

### 1. Why did I use 1000.0 rather than 1000 in the seconds calculation?

**My answer:** As per the question, I need to use `1000.0`.

**Review:** I initially identified the required formula. In question 2, I also explained why retaining the decimal part matters.

### 2. How could using the integer divisor 1000 affect the fractional part of Seconds?

**Hint:** Consider integer division versus decimal division in this calculation.

**My answer:** We will not get values in decimal points, but we want decimal values, so we used `1000.0`.

**Review:** I correctly identified the loss of fractional seconds with integer division. In SQLite, dividing integer milliseconds by integer `1000` truncates the fractional part; using `1000.0` retains fractional seconds.

### 3. How do ORDER BY Milliseconds desc and LIMIT 5 work together to select the five longest tracks?

**My answer:** `desc` sorts in decreasing order, so the largest values come to the top, and then I pick the top five.

**Review:** I correctly explained that the descending sort places the longest tracks first and `LIMIT 5` keeps the first five rows of that sorted result.
