# 25. Monthly revenue across the full history

## Question and image

Using the Chinook `Invoice` table, produce chart-ready total revenue for every month in the store's history, with one row per calendar month.

Return exactly two columns:

- `Month` — year and month formatted as `YYYY-MM`, for example `2023-07`
- `Revenue` — the sum of `Total` for that month, rounded to 2 decimal places

Sort by `Month` ascending.

The history spans several years. A result containing exactly 12 rows has incorrectly combined the same months from different years.

Expected output: `Month`, `Revenue` — 60 rows; order matters.

## My solution — SQLite

```sql
select
    strftime('%Y-%m', InvoiceDate) as Month,
    round(sum(Total), 2) as Revenue
from Invoice
group by Month
order by Month;
```

## My solution — SQL Server

```sql
select
    convert(char(7), InvoiceDate, 120) as Month,
    round(sum(Total), 2) as Revenue
from Invoice
group by convert(char(7), InvoiceDate, 120)
order by Month;
```

## Official solution

```sql
SELECT
    strftime('%Y-%m', InvoiceDate) AS Month,
    ROUND(SUM(Total), 2) AS Revenue
FROM Invoice
GROUP BY strftime('%Y-%m', InvoiceDate)
ORDER BY Month ASC;
```

### What this tests

Creating a year-month grouping key from a timestamp and aggregating revenue at the correct calendar-month level.

### The approach

1. Convert each `InvoiceDate` into a `YYYY-MM` label with `strftime('%Y-%m', InvoiceDate)`.
2. Group invoices by that year-month value so the same month in different years remains separate.
3. Sum each month's `Total` and round the result to two decimal places.
4. Sort by `Month` ascending. The zero-padded `YYYY-MM` format sorts chronologically as text.

### Why this way

Deriving the time bucket directly in the aggregation makes the result's monthly grain clear. Changing the format string allows the same pattern to create daily, weekly, or hourly summaries.

### Common mistakes

- Using only `%m`, which combines the same month from every year into 12 groups.
- Grouping by the complete timestamp, which creates separate groups for individual invoice dates or times.
- Sorting by revenue when the requested result is a chronological time series.
