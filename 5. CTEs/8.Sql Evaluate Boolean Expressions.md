# 8. SQL Evaluate Boolean Expressions

## Question and image

**8. Sql Evaluate Boolean Expressions**

Table Variables:

| Column Name | Type |
|---|---|
| name | varchar |
| value | int |

In SQL, `name` is the primary key for this table.

This table contains the stored variables and their values.

Table Expressions:

| Column Name | Type |
|---|---|
| left_operand | varchar |
| operator | enum |
| right_operand | varchar |

In SQL, (`left_operand`, `operator`, `right_operand`) is the primary key for this table.

This table contains a boolean expression that should be evaluated.

`operator` is an enum that takes one of the values (`'<'`, `'>'`, `'='`).

The values of `left_operand` and `right_operand` are guaranteed to be in the Variables table.

Evaluate the boolean expressions in Expressions table.

**Example 1:**

Example:"

Input:

Variables table:

| name | value |
|---|---|
| x | 66 |
| y | 77 |

Expressions table:

| left_operand | operator | right_operand |
|---|---|---|
| x | > | y |
| x | < | y |
| x | = | y |
| y | > | x |
| y | < | x |
| x | = | x |

Output:

| left_operand | operator | right_operand | value |
|---|---|---|---|
| x | > | y | false |
| x | < | y | true |
| x | = | y | false |
| y | > | x | true |
| y | < | x | false |
| x | = | x | true |

*Explanation:*

As shown, you need to find the value of each boolean expression in the table using the variables table.

## Schema

**Variables**  
name, value

- `name` - varchar, primary key
- `value` - int

**Expressions**  
left_operand, operator, right_operand

- `left_operand` - varchar, guaranteed to exist in `Variables.name`
- `operator` - enum containing `'<'`, `'>'`, or `'='`
- `right_operand` - varchar, guaranteed to exist in `Variables.name`
- (`left_operand`, `operator`, `right_operand`) is the composite primary key.

## My solution — SQLite

```sql
SELECT
    E.left_operand,
    E.operator,
    E.right_operand,
    (
        CASE
            WHEN E.operator = '>'
                 AND L.value > R.value THEN 'true'
            WHEN E.operator = '<'
                 AND L.value < R.value THEN 'true'
            WHEN E.operator = '='
                 AND L.value = R.value THEN 'true'
            ELSE 'false'
        END
    ) AS value
FROM Expressions AS E
JOIN Variables AS L
    ON E.left_operand = L.name
JOIN Variables AS R
    ON E.right_operand = R.name;
```
