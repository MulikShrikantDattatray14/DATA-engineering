# 14. SQL Shortest Distance In A Line

## Question and image

**LeetCode 613:** [Shortest Distance in a Line](https://leetcode.com/problems/shortest-distance-in-a-line/)

This is assignment question 9, saved as Question 14 in this section.

Find the shortest distance between any two points in the `Point` table. Each point lies on the X-axis.

Return one column named `shortest`.

**Example 1:**

Input — Point:

| x |
| ---: |
| -1 |
| 0 |
| 2 |

Output:

| shortest |
| ---: |
| 1 |

**Example explanation:** The closest points are -1 and 0. Their distance is `|(-1) - 0| = 1`.
