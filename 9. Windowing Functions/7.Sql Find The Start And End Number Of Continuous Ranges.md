# 7. SQL Find the Start and End Number of Continuous Ranges

## Question and image

**LeetCode 1285:** [Find the Start and End Number of Continuous Ranges](https://leetcode.com/problems/find-the-start-and-end-number-of-continuous-ranges/)

Write a solution to find the start and end number of continuous ranges in the table Logs.

Return the result table ordered by start_id.

**Example 1:**

Input:

Logs table:

| log_id |
| --- |
| 1 |
| 2 |
| 3 |
| 7 |
| 8 |
| 10 |

Output:

| start_id | end_id |
| --- | --- |
| 1 | 3 |
| 7 | 8 |
| 10 | 10 |

**Example explanation:** The continuous runs are 1–3, 7–8, and the single value 10.
