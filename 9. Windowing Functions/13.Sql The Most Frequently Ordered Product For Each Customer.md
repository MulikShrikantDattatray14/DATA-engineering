# 13. SQL The Most Frequently Ordered Product For Each Customer

## Question and image

**LeetCode 1596:** [The Most Frequently Ordered Products for Each Customer](https://leetcode.com/problems/the-most-frequently-ordered-products-for-each-customer/)

This is assignment question 8, saved as Question 13 in this section.

Find the most frequently ordered product or products for each customer who has placed at least one order. If a customer's products are tied for the highest order count, include all tied products.

Return `customer_id`, `product_id`, and `product_name`, ordered by `customer_id` and then `product_id`, both in ascending order.

**Example 1:**

Input — Customers:

| customer_id | name |
| ---: | --- |
| 1 | Alice |
| 2 | Bob |
| 3 | Tom |
| 4 | Jerry |
| 5 | John |

Input — Orders:

| order_id | order_date | customer_id | product_id |
| ---: | --- | ---: | ---: |
| 1 | 2020-07-31 | 1 | 1 |
| 2 | 2020-07-30 | 2 | 2 |
| 3 | 2020-08-29 | 3 | 3 |
| 4 | 2020-07-29 | 4 | 1 |
| 5 | 2020-06-10 | 1 | 2 |
| 6 | 2020-08-01 | 2 | 1 |
| 7 | 2020-08-01 | 3 | 3 |
| 8 | 2020-08-03 | 1 | 2 |
| 9 | 2020-08-07 | 2 | 3 |
| 10 | 2020-07-15 | 1 | 2 |

Input — Products:

| product_id | product_name | price |
| ---: | --- | ---: |
| 1 | keyboard | 120 |
| 2 | mouse | 80 |
| 3 | screen | 600 |
| 4 | hard disk | 450 |

Output:

| customer_id | product_id | product_name |
| ---: | ---: | --- |
| 1 | 2 | mouse |
| 2 | 1 | keyboard |
| 2 | 2 | mouse |
| 2 | 3 | screen |
| 3 | 3 | screen |
| 4 | 1 | keyboard |

**Example explanation:** Alice ordered the mouse three times and the keyboard once, so only the mouse appears. Bob ordered the keyboard, mouse, and screen once each, so all three tie. Tom ordered the screen twice, and Jerry ordered the keyboard once. John placed no orders, so he does not appear.
