# 4. SQL Second Highest Salary

## Question and image

[**176. Second Highest Salary**](https://leetcode.com/problems/second-highest-salary/)

Find the **second-highest distinct salary** in `Employee`. Return a single column named `SecondHighestSalary`. If the table has no second distinct salary, return one row containing `NULL`.

**Example 1 — input:**

Employee:

| id | salary |
|---:|---:|
| 1 | 100 |
| 2 | 200 |
| 3 | 300 |

**Output:**

| SecondHighestSalary |
|---:|
| 200 |

**Example 2 — input:**

Employee:

| id | salary |
|---:|---:|
| 1 | 100 |

**Output:**

| SecondHighestSalary |
|---|
| NULL |
