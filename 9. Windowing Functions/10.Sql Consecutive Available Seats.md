# 10. SQL Consecutive Available Seats

## Question and image

**LeetCode 603:** [Consecutive Available Seats](https://leetcode.com/problems/consecutive-available-seats/)

Find every free seat that has at least one adjacent free seat in the cinema.

Return the result table ordered by seat_id in ascending order.

The test cases are generated so that more than two seats are consecutively available.

**Example 1:**

Input:

Cinema table:

| seat_id | free |
| --- | --- |
| 1 | 1 |
| 2 | 0 |
| 3 | 1 |
| 4 | 1 |
| 5 | 1 |

Output:

| seat_id |
| --- |
| 3 |
| 4 |
| 5 |

**Example explanation:** Seats 3, 4, and 5 form a consecutive run of free seats. Seat 1 is free, but its neighboring seat 2 is occupied, so seat 1 is not in the result.
