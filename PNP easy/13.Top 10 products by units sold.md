# 13. Top 10 products by units sold

## Question and image

Using the Northwind database, the inventory team wants the ten best-selling products by total volume (not revenue). For each product, sum the `Quantity` sold across all order lines.

Tables involved: `"Order Details"`, `Products`.

Return exactly two columns:

- `ProductName`: the product name.
- `TotalUnitsSold`: the total quantity sold for that product.

Sort by `TotalUnitsSold` in **descending** order; break ties by `ProductName` in **ascending (A–Z)** order. Return only the **top 10 rows**.

**Expected output:** `ProductName`, `TotalUnitsSold` · 10 rows · order matters.

## My solution — SQLite

```sql
select ProductName , sum ("Order Details".Quantity) as TotalUnitsSold
from "Order Details"
join Products on Products.ProductID = "Order Details".ProductID
group by Products.ProductID
order by TotalUnitsSold desc , ProductName asc
limit 10
```

## My solution — SQL Server

```sql
select TOP (10) ProductName , sum ([Order Details].Quantity) as TotalUnitsSold
from [Order Details]
join Products on Products.ProductID = [Order Details].ProductID
group by Products.ProductID, Products.ProductName
order by TotalUnitsSold desc , ProductName asc
```

## Official solution

```sql
SELECT p.ProductName,
       SUM(od.Quantity) AS TotalUnitsSold
FROM "Order Details" od
JOIN Products p ON od.ProductID = p.ProductID
GROUP BY p.ProductName
ORDER BY TotalUnitsSold DESC, p.ProductName ASC
LIMIT 10;
```

### What this tests

Joining tables, summing quantities, ranking results through sorting, and limiting output.

### The approach

Join order details to products; sum Quantity per product name; sort total units descending and name ascending; keep ten rows.

### Why this way

The join supplies product names and GROUP BY gathers each product's sales quantities for SUM.

### Common mistakes

Missing or incorrect joins, omitting grouping, or filtering out valid order lines before calculating total units.
