# 2. Top five genres by revenue

## Question and image

Find the five genres that generated the most revenue in the Chinook store. Line-level revenue is `InvoiceLine.UnitPrice * InvoiceLine.Quantity`. Join `InvoiceLine` → `Track` → `Genre` to attribute each sold line to a genre.

Return exactly two columns:

- `Genre` — the genre name (`Genre.Name`).
- `Revenue` — the total revenue for that genre, rounded to **2 decimal places**.

Sort by `Revenue` in **descending** order; break ties by `Genre` ascending. Return only the **top 5 rows**.

**Expected output:** `Genre`, `Revenue` · 5 rows · order matters.

## My solution — SQLite

```sql
select Genre.Name as Genre , round (sum(InvoiceLine.UnitPrice * InvoiceLine.Quantity),2) as Revenue
from InvoiceLine
join Track on InvoiceLine.TrackId = Track.TrackId
join  Genre on Genre.GenreId=Track.GenreId
group by Genre.GenreId
order by Revenue desc, Genre asc
limit 5
```

## My solution — SQL Server

```sql
select TOP (5) Genre.Name as Genre , round (sum(InvoiceLine.UnitPrice * InvoiceLine.Quantity),2) as Revenue
from InvoiceLine
join Track on InvoiceLine.TrackId = Track.TrackId
join  Genre on Genre.GenreId=Track.GenreId
group by Genre.GenreId, Genre.Name
order by Revenue desc, Genre asc
```

## Official solution

```sql
SELECT g.Name AS Genre,
       ROUND(SUM(il.UnitPrice * il.Quantity), 2) AS Revenue
FROM InvoiceLine il
JOIN Track t ON il.TrackId = t.TrackId
JOIN Genre g ON t.GenreId = g.GenreId
GROUP BY g.Name
ORDER BY Revenue DESC, Genre ASC
LIMIT 5;
```

### What this tests

Joining multiple tables, calculating revenue, grouping, rounding, and returning the top results.

### The approach

Join invoice lines to tracks and genres; sum line price × quantity by genre; round to two decimal places; sort by revenue descending and genre ascending; keep five rows.

### Why this way

The direct joins connect each sale to its genre, allowing one grouped revenue calculation.

### Common mistakes

Selecting track names instead of genre names, omitting LIMIT 5, or using joins that duplicate sales and inflate revenue.
