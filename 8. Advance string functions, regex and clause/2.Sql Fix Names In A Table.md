Table: `Users`

| Column Name | Type |
|---|---|
| user_id | int |
| name | varchar |

user_id is the primary key (column with unique values) for this table.

This table contains the ID and the name of the user.

The name consists of only lowercase and uppercase characters.

Write a solution to fix the names so that only the first character is uppercase and the rest are lowercase.

Return the result table ordered by `user_id`.

The result format is in the following example.

**Example 1:**

**Input:**

Users table:

| user_id | name |
|---|---|
| 1 | aLice |
| 2 | bOB |

**Output:**

| user_id | name |
|---|---|
| 1 | Alice |
| 2 | Bob |

The following SQL was supplied in the class notes. It is kept separate from your pending solution.

```sql
SELECT Users.user_id , CONCAT(UPPER(SUBSTR(Users.name,1,1)),LOWER(SUBSTR(Users.name,2))) AS name
FROM Users
ORDER BY
Users.user_id ASC
```

### What this tests

Extracting parts of a name, changing their case, and joining them into a formatted name.

### The approach

Take the first character with `SUBSTR(name, 1, 1)` and apply `UPPER`. Take the remaining characters from position 2 and apply `LOWER`. Join the pieces with `CONCAT` and order by `user_id`.

### Why this way

The first character and the remaining characters need different case transformations. The expression preserves one result row for each user.

### Common mistakes

- Applying the same case function to the entire name.
- Starting the remaining substring at the wrong position.
- Omitting the requested order.
- Assuming these function names and argument forms work in every SQL engine. This is the class-provided syntax; the learner's SQLite solution and SQL Server adaptation remain pending.
